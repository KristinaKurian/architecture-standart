# Task4. Передача ставок в кол-центр

## Артефакты

- `ADR.md` — архитектурное решение по передаче депозитных ставок;
- `rate_distribution_c4.drawio` — C4 Context и C4 Container;
- `System_tasks.md` — задачи для каждой системы;
- `RoadMap_bank_Standart.drawio` — RoadMap;

## Принятое решение

АБС остаётся источником истины. Сервис интеграции депозитов получает подтверждённые версии ставок через контролируемый API и распространяет их двумя способами:

- внутренний кол-центр — HTTPS REST API;
- партнёрский кол-центр — CSV + manifest через SFTP.

Файлы для партнёра не содержат персональных данных. Каждая публикация имеет номер версии, дату действия и контрольную сумму.

## Допущения

- значения p95, доступности и свежести помечены в ADR как предварительные;
- для партнёра выбран наиболее слабо связанный канал из шаблона — SFTP;
- механизм подтверждения успешного импорта должен быть согласован с партнёром;
- решение переиспользует сервис интеграции с АБС, выбранный в Task3.
