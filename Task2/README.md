Task2. Требования по модели FURPS+

В файле FURPS+.md собраны требования к развитию сайта, интернет-банка, АБС и системы кол-центра для открытия депозитов и накопительных счетов онлайн.

Требования разделены на:

Functionality;

Usability;

Reliability;

Performance;

Supportability;

Restrictions.

В комментариях архитектурно значимые требования отмечены обозначением ASR. В конце файла приведена отдельная сводная таблица ASR, которая будет использоваться как вход для ADR в задании 3.
