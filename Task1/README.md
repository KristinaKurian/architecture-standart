# Task1. Карта IT-ландшафта и схема интеграции приложений

## Обновлённые артефакты

- `01_current_it_landscape.drawio` — карта текущего IT-ландшафта.
- `02_application_integration_as_is.drawio` — схема интеграции.

## Основные проблемы AS-IS

- интернет-банк напрямую обращается к базе данных АБС;
- сайт не поддерживает заявки на депозит;
- ставки рассчитываются вручную в Excel;
- согласования выполняются по email;
- процесс зависит от сотрудников бэк-офиса;
- открытие депозита занимает от 20 минут до часа.
